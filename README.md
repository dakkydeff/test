# KindleToPDF

Kindle for Mac で開いている本を **1ページずつ画面キャプチャし、1つの PDF にまとめる** macOS アプリです（SwiftUI / macOS 14 以降）。

- Kindle のウィンドウだけを ScreenCaptureKit でキャプチャし、右矢印キー（→）を Kindle に送ってページをめくります。
- 同じ画面が指定回数続いたら「本の終わり」と判断して自動で停止し、PDF を保存します。
- **DRM の解除は一切行いません。** Kindle の本のファイル（.azw / .kfx など）には触れず、画面に表示されたピクセルを撮影するだけです。

> **個人利用のみ。** 著作権法上の私的複製の範囲内でご利用ください。作成した PDF を第三者に配布・共有・公開しないでください。Kindle の利用規約も確認のうえ、自己責任でご利用ください。

## 動作環境

- macOS 14 (Sonoma) 以降
- Xcode Command Line Tools（`xcode-select --install`）または Xcode 15 以降（Swift 5.9 以上）
- Kindle for Mac

## ビルド

```sh
make install  # ビルドして /Applications/KindleToPDF.app にインストール（おすすめ）
make app      # build/KindleToPDF.app を作成（release ビルド + ad-hoc 署名）
make run      # build/KindleToPDF.app を起動（未ビルドならビルドしてから）
make test     # ロジック部分（CaptureCore）のユニットテスト
make uninstall # /Applications から削除
make clean    # .build と build を削除
```

### アプリケーションフォルダに入れて、いつでも起動できるようにする

```sh
git clone -b claude/kindle-to-pdf-mac-app-ilmvyx https://github.com/dakkydeff/test.git KindleToPDF
cd KindleToPDF
make install
```

これで `/Applications/KindleToPDF.app` が作られ、**Launchpad・Spotlight（⌘Space で「KindleToPDF」）・Finder の「アプリケーション」** から他のアプリと同じように起動できます。Dock に残したい場合は、起動中の Dock アイコンを右クリック → オプション → 「Dock に追加」を選んでください。

`/Applications` に書き込めない場合は、ホーム直下の Applications フォルダに入れられます。

```sh
make install INSTALL_DIR=~/Applications
```

権限（画面収録・アクセシビリティ）は **インストール後に起動した KindleToPDF で許可** してください。`build/` 内のアプリで先に許可しても、同じビルドをコピーしているので通常はそのまま有効ですが、効かない場合は下記「権限が保持される条件について」の手順でリセットしてください。

アップデートするときは `git pull` のあと `make install` をもう一度実行します（再ビルドで署名が変わるため、権限の付け直しが必要になることがあります）。

`make app` は `scripts/build-app.sh` を実行します。内部では次の処理を行います。

1. `swift build -c release --product KindleToPDF`
2. `build/KindleToPDF.app` を組み立て（実行ファイル・`Info.plist`・`PkgInfo`・`AppIcon.icns`）
3. `codesign --force --deep --sign - build/KindleToPDF.app`（ad-hoc 署名）

できあがった `build/KindleToPDF.app` は `make install` で `/Applications` にコピーできます（手動で Finder からドラッグしても構いません）。

## 権限の設定

このアプリには 2 つの権限が必要です。アプリ画面の上部に状態（緑 = 許可済み / 赤 = 未許可）が表示され、未許可なら「システム設定を開く」ボタンから設定画面を開けます。

| 権限 | 用途 | 場所 |
| --- | --- | --- |
| 画面収録 | Kindle ウィンドウのキャプチャ | システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音 |
| アクセシビリティ | ページ送りキー（→）の送信 | システム設定 → プライバシーとセキュリティ → アクセシビリティ |

1. KindleToPDF を起動し、「システム設定を開く」を押します。
2. 一覧の **KindleToPDF** をオンにします（一覧に無ければ「+」から `KindleToPDF.app` を追加）。
3. 画面収録は、許可した後に **KindleToPDF の再起動** が必要な場合があります。

### 権限が保持される条件について

`Info.plist` で bundle id を `jp.local.KindleToPDF` に固定しているため、同じビルドを使い続ける限り、再起動しても権限は保持されます。

ただし ad-hoc 署名のアプリは、**ビルドし直すと署名（コードのハッシュ）が変わる** ため、macOS が別のアプリとみなして権限が効かなくなることがあります（設定画面ではオンに見えるのに動かない、など）。その場合は次のどちらかを行ってください。

- システム設定の一覧で KindleToPDF を「−」で削除し、もう一度追加してオンにする
- ターミナルでリセットしてから、改めて許可する
  ```sh
  tccutil reset ScreenCapture jp.local.KindleToPDF
  tccutil reset Accessibility jp.local.KindleToPDF
  ```

自分の署名用証明書（「キーチェーンアクセス」で作成した自己署名のコード署名証明書など）を持っている場合は、`CODESIGN_IDENTITY="証明書名" make app` で署名すると、再ビルド後も権限が保持されやすくなります。

## 使い方

1. **Kindle for Mac で本を開き、最初に撮りたいページ（通常は表紙か1ページ目）を表示しておきます。** ここから撮影が始まります。
   - Kindle の表示設定（単ページ表示・文字サイズ・ウィンドウサイズ）は撮影前に決めておいてください。ウィンドウが大きいほど高解像度の PDF になります。
2. KindleToPDF を起動し、権限が両方とも緑になっていることを確認します。
3. 「キャプチャするウィンドウ」で Kindle のウィンドウを選びます。見つからない場合は「更新」を押してください。Kindle の bundle id が想定と異なる場合は「Kindle 以外のウィンドウも表示する」をオンにして選びます。
4. 設定を調整します。
   - **ページ送り間隔**: ページをめくってから次に撮影するまでの秒数（0.3〜10 秒、既定 1.0 秒）。ページめくりのアニメーションが写り込む場合は長くしてください。
   - **最大ページ数**: 安全のための上限（1〜10000、既定 2000）。
   - **終了判定**: 同じ画面が何回続いたら本の終わりとみなすか（2〜10 回、既定 3 回）。
   - **動作モード**: 既定は **バックグラウンドモード**。Kindle を前面に出さず、Kindle のプロセスに直接ページ送りキーを送り、ウィンドウが他のウィンドウの後ろや別の画面（Space）にあっても撮影を続けます。撮影中に Mac で他の作業ができます。Kindle が背面ではページ送りに反応しない場合だけ「Kindle を前面に出して撮影する（前面モード）」をオンにしてください。
   - **トリミング (px)**: 上・左・下・右から切り落とすピクセル数（撮影画像のピクセル単位。Retina では見た目の約2倍）。
5. 「出力」でタイトルと保存先を指定します。保存先を指定しない場合はデスクトップに保存されます。
6. 「開始」を押します。撮影とページ送りが自動で進みます。バックグラウンドモードなら他のアプリに切り替えたり別の画面（Space）に移動したりして構いません。ただし **Kindle を最小化（Dock にしまう）したり終了したりしないでください**。また Kindle 自体をマウスやキーボードで操作しないでください（表示が変わると終了判定に影響します）。
7. 本の終わりを検出すると自動で停止し、PDF を保存します。末尾の重複ページは自動で除外されます。
8. 途中でやめるときは、KindleToPDF のウィンドウで「停止」を押します（前面モードのときは、KindleToPDF が前面にある間は撮影が一時停止し、Kindle をクリックすると再開します）。停止すると、それまでのページで PDF を保存するか選べます。

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| ページがめくられない | **アクセシビリティ** の許可を確認してください。バックグラウンドモードで Kindle が反応しない場合は「Kindle を前面に出して撮影する（前面モード）」をオンにしてください。許可済みに見える場合は、一覧から削除して追加し直すか `tccutil reset Accessibility jp.local.KindleToPDF` を実行してください。Kindle で → キーを手で押してページがめくれるかも確認してください。 |
| 撮影画像が真っ黒・何も写らない / ウィンドウ一覧が空 | **画面収録** の許可を確認し、KindleToPDF を再起動してください。ビルドし直した後は許可の付け直しが必要なことがあります。 |
| 最後のページが何枚も入る | 「終了判定」の回数分の重複は自動で除外されます。それでも残る場合は、最終ページで Kindle の表示がわずかに変化している可能性があります。トリミングで変化する部分（進捗表示など）を除くか、手動で削除してください。 |
| 途中で止まってしまう（本の途中で終了と判断される） | ページ送りが間に合っていない可能性があります。「ページ送り間隔」を長くするか、「終了判定」の回数を増やしてください。 |
| ページめくりの途中の画面が写る | 「ページ送り間隔」を長くしてください。 |
| 「Kindle を前面にできませんでした」と表示される | 前面モードのときのメッセージです。Kindle のウィンドウを一度クリックしてください。撮影が再開されます。 |
| 「対象のウィンドウが見つかりません」で止まる | Kindle が最小化（Dock にしまわれている）か終了しています。ウィンドウを戻してから、もう一度「更新」→「開始」してください。 |
| エラーで止まった | ログに表示される一時フォルダに、それまでに撮影した PNG が残っています。 |

## 既知の制限

- macOS 14 以降専用です（ScreenCaptureKit の `SCScreenshotManager` を使用）。
- バックグラウンドモードでは Kindle を最小化できません（ウィンドウの描画内容を撮るため）。他のウィンドウの後ろや別の Space にあるのは問題ありません。
- 前面モードでは撮影中 Kindle が前面にある必要があり、その間 Mac で他の作業はできません。
- 画像は等倍（1px = 1pt）でそのまま PDF に埋め込むため、ページ数が多いと PDF のファイルサイズが大きくなります。文字検索（OCR）には対応していません。
- 見開き表示や縦書きの本では、Kindle 側の → キーの動作（次ページ/前ページ）が本によって異なる場合があります。縦書きの本で逆方向に進む場合は、Kindle 側で表示を確認してください。
- ページが変化しないページ（白紙ページが連続するなど）が「終了判定」の回数以上続くと、そこで終了と判断されます。その場合は回数を増やしてください。
- 本の途中でポップアップ（「本の終わり」の評価画面など）が表示されると、それも撮影されます。
- ad-hoc 署名のため、ビルドし直すと権限の付け直しが必要になることがあります（上記参照）。

## 開発者向け

- `Sources/CaptureCore` — AppKit / ScreenCaptureKit に依存しない純粋な Swift のロジック（設定値、フレームのハッシュ、終了判定、状態遷移、末尾重複の計算）。Linux でも `swift test` が通ります。
- `Sources/KindleToPDF` — macOS アプリ本体（SwiftUI + ScreenCaptureKit + CoreGraphics）。全ファイルが `#if os(macOS)` で囲まれています。
- 設計は [`docs/DESIGN.md`](docs/DESIGN.md) を参照してください。
